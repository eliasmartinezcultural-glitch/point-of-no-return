## Seguridad
Este repositorio es público. La V1 usa claves de demostración y almacenamiento local para validar la experiencia, NO seguridad real. No colocar teléfonos reales, documentos, contraseñas, contratos ni otra información sensible hasta implementar una capa de autenticación y datos privados.

Claves de demostración: PNR-ELIAS / PNR-DANIEL / PNR-MARIA / PNR-LINA.

La aplicación incluye service worker para mantener la interfaz disponible sin conexión una vez visitada/instalada.
